# RetailPulse — E-Commerce Sales Analytics

> End-to-end data analytics project analyzing 100,000+ real orders
> from a Brazilian e-commerce platform to surface actionable
> business insights for revenue growth and customer retention.

## Project Overview
RetailPulse analyzes the Olist Brazilian E-Commerce dataset to answer
critical business questions about revenue performance, customer behavior,
delivery operations, and product performance.

## Key Findings
- 📦 **3.12% repeat purchase rate** — critical loyalty problem identified
- 🚚 **Delivery drives satisfaction** — 1-star reviews average 20.8 days delivery vs 10.2 days for 5-star
- 📍 **São Paulo = 44% of revenue** — dangerous geographic concentration
- 👥 **25% Champions, 31% At Risk** — RFM segmentation of 93,355 customers

## Tech Stack
- **Python** — Pandas, Matplotlib, Seaborn
- **SQL** — MySQL with window functions and CTEs
- **Power BI** — 3-page interactive dashboard
- **Jupyter Notebooks** — end-to-end analysis pipeline

## Dataset
Olist Brazilian E-Commerce Public Dataset
Download from: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## How to Run
1. Clone this repository
2. Download dataset from Kaggle and place CSVs in `Data/raw/`
3. Install dependencies: `pip install -r requirements.txt`
4. Run notebooks in order: 01 → 02 → 03 → 04 → 05

## Business Recommendations
1. **Fix repeat purchase rate** — regional logistics partnerships
2. **Reduce delivery to under 10 days** — target 5-star reviews
3. **Expand to underserved states** — BRL 1.54M revenue opportunity
4. **Audit health & beauty category** — save BRL 246K in return costs
